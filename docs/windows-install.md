# 顺位输入法 Windows 开发版

2026-10-20，0.2.0-dev。此包是 TSF 系统输入法，包含 x64 和 x86 DLL，不是网页封装或独立打字窗口。

## 安装和启用

1. 在 x64 Windows 10/11 测试机运行 `Shunwei-0.2.0-dev-Windows-Setup.exe`，按系统提示允许安装器注册COM/TSF组件。
2. 确保系统已添加“中文（简体，中国）”。在系统设置 → 时间和语言 → 语言选项 → 键盘中添加“顺位输入法（开发版）”。页面名称随Windows版本不同；列表不可见时退出登录后重试。
3. 用Win+空格切换到顺位。默认拼音，空格选词，Return原文，Esc取消组合，左右移动光标，上下选候选。
4. 当前原文保护较保守：含数字、网址、邮箱、路径或下划线的整串保留原文。

没有代码签名证书，Windows可能显示未知发布者。先在测试电脑或虚拟机使用，保留系统自带输入法。安装器不自动激活顺位或替换当前输入法。

## 测试顺序

先打开记事本，测试 `woaini`、`nihao`、`aizidongdazi`，验证候选存在并可选择、空格和Return不同、Esc不删除正文。再测试选词、退格、左右光标、Ctrl+C/V、Alt+Tab、宿主失焦、密码框。最后测试Edge、Word和微信，分别记录64/32位宿主。

Windows原生候选优先中文；若“爱自动打字”居首，按上下键选择“AI 自动打字”。Windows版尚未实现语境输入或AI重排，不能承诺自动理解AI/爱。

安装目录内的 `x64/engine-check.exe` 可测试解码词典，命令行传入其 `data` 目录。GitHub Actions也配置了Windows编译及解码检查；在上传并运行之前不能声称Actions已经通过。

## 卸载

先切换到系统自带输入法，在语言设置移除顺位，再从“已安装的应用”卸载“顺位输入法（开发版）”。如果DLL被Word/微信等占用，退出这些应用并重新登录后完成卸载；安装器允许重启后删除仍被占用的DLL。

## 当前验证边界

Windows系统接口代码已编写；Mac上的Windows交叉编译和PE静态检查只能验证构建，不能证明Windows安装、注册、候选窗口和宿主兼容性。Windows运行验证需要真正的Windows环境。

原生C++解码共享同一份词典与启发式，但尚不与TypeScript逐项完全一致。当前Windows版只接受ASCII无调全拼，音节隔音符、英文和技术缩写；带调拼音、ü快捷编码、用户词条管理、已提交文本恢复和Windows现代应用兼容性后续完善。Windows版不会读取其他应用全文、调用云端模型或监听全局按键。
