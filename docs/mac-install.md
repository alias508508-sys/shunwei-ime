# Mac 本地安装、启用与卸载

首个 Apple Silicon 内测构建；实际构建环境 macOS 26.6.2，Xcode SDK，最低编译目标 macOS14。其他系统版本和 Intel 未验证。本应用为本机 ad-hoc 签名，未公证，不是正式发布安装包。

## 安装

推荐打开 `releases/Shunwei-0.2.0-dev-macOS-arm64.dmg`，双击其中“安装顺位输入法.app”。不需要Node或终端。源码目录下的脚本安装方式仍可用。

在项目目录双击 `安装Mac输入法.command`，或运行：

```bash
bash scripts/install-mac.sh
```

仅复制到当前用户 `~/Library/Input Methods/Shunwrite.app`，没有开启或切换输入源。遇到已有同名应用会先改名备份，不删除旧版。升级前应切换到其他输入法，并退出旧进程；如旧进程仍存在，退出登录再重新登录后测试新版。

## 启用

打开系统设置 → 键盘 → 文本输入 → 编辑 → 添加输入源，寻找中文分类中的“顺位 / Shunwrite”。不同 macOS 版本文字可能不同；若暂未出现，退出登录后重新登录。选择它后在菜单栏切换到该输入法。

不要直接把双击 `.app` 启动成功当作系统输入法已注册。首次用户启用和列表是否可见尚未测试，需要按下列清单记录结果。

## 首次测试

在 TextEdit 新建空文档：

1. 输入 `aizidongdazi`，观察组合区和候选；空格应得到“AI 自动打字”。
2. 输入 `woaini`，Return 应提交原文 `woaini`。
3. 输入 `nihao`，Esc 应取消当前组合，不删除此前正文。
4. 测试左右移动、选区替换、退格和上下选词。
5. 输入完整网址后空格确认，网址应保持原文。
6. 使用输入法菜单添加/删除词条、选择英文锁定/自动混输。
7. 使用菜单“恢复刚提交的原文”；选区变化时应拒绝恢复，不盲删。
8. 再在浏览器和办公软件重复测试。未测试的应用记“未测”。

候选窗定位必须由真实宿主提供；无有效位置时不弹出窗口，空格仍提交排序候选，Return 保留原文。密码等安全输入场景依赖系统与宿主约束；本程序没有全局键盘监听，也不读取周边正文。

## 卸载

先切换到其他输入法，在系统设置移除“顺位”，再双击 `卸载Mac输入法.command`，或：

```bash
bash scripts/uninstall-mac.sh
```

应用移至废纸篓，可以恢复。旧版备份与用户词条保留。若要清除词条，可用应用菜单“管理用户词条”，或自行删除 `~/Library/Application Support/Shunwrite/entries.json`。

## 开发构建

```bash
npm ci
npm run build:mac
```

脚本编译、ad-hoc 签名，并运行 JavaScriptCore 13组一致性检查及协调器协议测试。此结果不代替系统启用和真实宿主测试。
