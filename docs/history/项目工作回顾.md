# 顺位输入法：前期工作回顾

整理日期：2026-10-25。依据本项目设计文档、源码、测试、构建产物及实际工具检查整理，不把规划功能写成已完成能力。

## 2026-10-09：需求和设计

起点是中英文切换造成的误输。典型字符串 `aizidongdazi`，希望获得“AI 自动打字”等候选。方案选择在同一输入法内部联合识别拼音和英文，保留候选与原文，而不是反复切换系统已有输入源。

形成开发框架、流程图、数据规范、架构、阶段计划和验收清单，并按用户选择建立 Mac 输入法＋网页原型路线。

## 2026-10-09：网页和Mac原型

建立同源词典、拼音/英文联合分词和排序、编辑会话、原文回退、用户词条。网页实现逐键体验与整串误输修复，经过真实浏览器操作检查。

Mac通过InputMethodKit接入，使用JavaScriptCore调用同一份TypeScript解码。建立组合协调器、候选窗、模式菜单、受控恢复、用户词条与构建脚本。完成编译、解码一致性、协议客户端及服务启动检查，未据此声称完成真实宿主验收。

项目名称由“顺写”调整为“顺位输入法”，网页和Mac启动默认改为拼音（中文优先）。内部标识和存储路径保留Shunwrite命名，避免破坏既有词条兼容性。

## 2026-10-20：DMG和Windows EXE

Mac新增图形安装器与DMG，提供用户级安装、备份和卸载路径。DMG通过校验、只读挂载和载荷检查。

Windows新增原生C++词典解码及TSF接口、x64/x86构建、NSIS安装器、注册/卸载逻辑。使用Mac上的LLVM-MinGW交叉编译，12项可移植解码检查通过；Windows实机安装、注册和宿主打字尚未验证。

曾发现默认中文优先挤掉混输候选的问题，增加通用的混输解释保留规则，使“爱自动打字”和“AI 自动打字”均能保留。神经AI重排仍未接入。

当时仅准备GitHub源码包和构建工作流，没有上传。之后只读检查确认Mac系统输入源枚举可识别“顺位输入法”，指导用户通过系统设置添加；这不等同于证明真实输入兼容性已通过。

## 2026-10-25：公开发布整理

用户明确授权公开上传源码与安装包。整理面向公众的首页、截图、历史方案、文档索引、平台说明和验证边界，检查安装包哈希、源码内容和忽略规则，准备通过GitHub Release提供下载。

当前优先工作仍是：真实Mac/Windows宿主测试、独立意图验收集、候选质量改进、本地AI重排，以及后续规范审核后的拼音学习应用。
